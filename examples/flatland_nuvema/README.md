# 마름꽃마을 — FlatLand v0.2 rc3

Pokémon Black의 Nuvema Town(마름꽃마을) 연구소·중앙 집·남쪽 집 두 채·북쪽 출구·남쪽 해안 배치를 재구성한 기능 데모입니다. Pokémon의 그래픽/음악/캐릭터 파일을 포함하지 않습니다. 이 데모의 새 스프라이트와 배경은 직접 제작한 CC0 에셋입니다. 레퍼런스: https://serebii.net/pokearth/unova/nuvematown.shtml

이동 WASD/방향키/4방향 조이스틱. Z/Space 대화, X 시점 선택, C 걷기48/달리기72px/s. 연구소 동료 선택 → 집 앞 친구와 전투. 기술 PP/가방/방어/전투 저장. 연구소에는 밀리는 상자, 고정 인형, 통과 가능한 표식이 있습니다. 인형은 Z/Space로 타격합니다. 시점은 탑뷰/경사/상층이며 상층에서는 낮은 울타리를 넘어갈 수 있습니다. 해안 표지판은 카메라 컷씬. 메뉴에서 퀘스트/인벤토리/저장. 모든 새 그래픽 CC0-1.0. 음악과 효과음은 기존 Signal Yard의 자체 제작 CC0 음원을 재사용합니다.
