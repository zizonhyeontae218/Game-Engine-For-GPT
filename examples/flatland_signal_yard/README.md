# Signal Yard — FlatLand 0.2 feature laboratory

A complete playable industrial adventure using original CC0 PNG sprites and WAV cues.
Import `flatland-signal-yard.ge4g` into GE4G, or launch its embedded desktop package.
Accept the guide's mission, collect the yellow key, open the red gate, defeat the red
security robot, then win at the purple arena terminal. Your quest awards 10 coins once.
The green terminal shows a separate cutscene and returns actors/camera to their exact positions.

| Input | Action |
|---|---|
| Joystick / WASD / arrows | Move |
| Z | Directional sword, with startup and recovery |
| X | Visible projectile; map walls and collision planes filter hits |
| C | Consume a healing kit |
| SPACE / E | Talk, open gate, use ramp or terminal |
| Menu | Save/load, inventory, equipment, quest log, controls, sound |

Mobile buttons are packaged JSON presets. Profile edits and mappings remain game-specific.
Orientation changes only through the rotation button. Dialogues and turn battle offer
explicit choices and an in-scene save button. Save during a choice or battle, load, and
continue: turn order, quest progress and seeded randomness resume.

Explore the crate station: the left chain is blocked by a fixed beacon; the free crate
moves; the hologram is passable. The cyan ramps switch plane and visual elevation.
Bridge cells block ground actors but permit upper-plane movement. The canopy covers
actors without changing collision. The guide uses an atlas and animation markers;
cutscenes play a named once clip while parent actors and timers pause.

The red robot uses sight/attack AI with facing, hit immunity, HP and drops. The orange
robot patrols fixed waypoints. Equipment adds attack strength. Turn combat supports
attack target, guard and healing items, speed order, victory/defeat and once-only effects.
Lua loads one declared project module and uses deterministic integer RNG.

The authored corpus `replays/journey.json` exercises adventure/combat, an item-gated
puzzle, patrol movement, bridge planes, turn RPG, quest and cutscene return. The engine
systems tests additionally cover invalid operations, atomic rollback, projectile walls,
choice/turn resume, RNG repeatability and revision-checked resource edits.

```sh
ge4g test examples/flatland_signal_yard --json
ge4g capabilities --json
ge4g resource examples/flatland_signal_yard data/systems.json5 gameplay/attacks/blade --json
```

The replay finishes at tick 714 with the mission complete, 13 coins and player at (80,240).
Sprites/audio can be regenerated by `python3 scripts/make_signal_yard_assets.py`.
Audio playback needs a working platform audio output; headless evidence proves commands,
not human audibility. New mobile device acceptance remains a separate check.
