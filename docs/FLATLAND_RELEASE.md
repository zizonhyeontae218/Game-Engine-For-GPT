# Basement 0.2 — FlatLand 0.2.0

Finalization target: Rust0.2.0 / Flutter0.2.0+8 / Android versionCode8. Android and
Windows only; iOS/macOS/Linux deferred until0.3. Existing application ID and release
certificate retained. Historical rc1–rc5 binaries/provenance are preserved.

## Included systems

Presentation-only persistent views, upright world composition, contact shadows and
feet ordering, solid South-only semantic building fallbacks, step movement, combat,
inventory/quests, persistent combatants HP/PP, event scenes, turn battles/battle FX,
actor-linked speech bubbles, Lua5.4/deterministic RNG, cue/music adapters and schema2
exact-once save/resume. Harbor Workshop is the independent original CC0 public sample.

Finalization adds optional native-resolved speakers, safe stable-game_id import/update,
typed incompatible-save archival, rollback, duplicate prevention, reorder and two
confirmed delete levels. Embedded Windows exposes no library management.

promotion after this focused pass. No rc6 required. Renderer/combat/save/input remain
frozen. New speaker/library behavior is covered by automated final tests; do not
